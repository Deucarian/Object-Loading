# Security policy

## Supported versions

Security fixes are considered for the current `main` package channel. `develop` is a preview channel and may receive a fix before promotion. Older commits and locally modified copies are not guaranteed to receive backports.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/Deucarian/Object-Loading/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Include the affected package version or commit, Unity version and platform, impact, source/resolver context, a minimal reproduction or proof of concept, and known mitigations. Redact signed URLs, tokens, private asset names, and personal data.

The maintainers will triage the report in GitHub's private advisory, may ask for additional evidence, and will coordinate disclosure after a fix or mitigation is available. No response or remediation deadline is guaranteed.

Security scope includes URL and metadata handling, AssetBundle/object lifecycle, resolver behavior, diagnostics serialization, and package samples. Unity, hosting services, and separately resolved dependencies retain their own security processes.
