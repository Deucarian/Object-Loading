# Support for Deucarian Object Loading

Use [GitHub Issues](https://github.com/Deucarian/Object-Loading/issues) for reproducible object, scene, URL, AssetBundle, resolver, handle, or lifecycle defects; documentation gaps; and narrowly scoped feature requests. Search existing issues before opening a new one.

Include the package version, Unity editor version and target platform, source type, lifecycle sequence, the smallest reproduction, expected and actual state/result, and full diagnostics with private URLs and credentials redacted.

`main` is the stable package channel. `develop` is a preview channel and may change before promotion. Please reproduce against the applicable current channel before reporting an older snapshot.

Do not disclose vulnerabilities, signed URLs, tokens, private assets, or user data in an issue. Follow [SECURITY.md](SECURITY.md) for private security reports.

Support is provided on a best-effort basis. API-backed transport belongs in the separate integration package, and Unity/hosting-service support remains with those providers.
